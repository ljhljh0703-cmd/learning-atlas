# 게임업계 사내 AI 조직·도구 지형 (2025~2026)

> ⚠️ **임시(provisional) · 게이트 미통과.** 대부분 2차 보도(기사)·기업 자기보고 기반이다. **수치를 그대로 인용하지 말고** "보도 기준"으로 표기한다. 조직명·수치는 입사 후 실측/1차 자료로 대조해 갱신한다.

## 0. 왜 이 노트가 필요한가

위메이드엑스알 PR기술개발팀 직무 = *"AI 기반 워크 플랫폼 제작·유지보수 + AI 도구 사내 배포·운영 + 신기술 조사·검증"*. 이건 업계에서 **"게임 안의 AI"가 아니라 "만드는 사람의 AI"** 축이다. 두 축을 구분하지 못하면 회의에서 엉뚱한 레퍼런스를 든다.

| 축 | 대상 | 국내 대표 |
|---|---|---|
| **A. 게임 안의 AI** | NPC·에이전트·안티치트·밸런싱·매칭 | 크래프톤 AI For Game R&D실, NC AI, 스마일게이트 AI센터 |
| **B. 만드는 사람의 AI** ⭐ 우리 축 | 사내 도구 배포·워크플로우 플랫폼·AX 확산·생산성 | 크래프톤 AX(포털·FDE), 넥슨 AI본부, 넷마블 AI전략실, 컴투스 AX HUB |

## 1. 국내 — 배포 모델 4종 (이게 핵심)

`[확인]` NDC26에서 넥슨·크래프톤이 자사 AX 여정을 나란히 발표했고, 두 회사가 **정반대 확산 전략**을 썼다는 점이 이 지형의 골자다.

### ① 크래프톤 — **톱다운 + 인프라 선투자**
- 2025-11 전사 **"AI First"** 선언. 신규 오리지널 IP·딥러닝 인력 제외 **전사 채용 동결**(CFO: "비용 절감이 아니라 개인 생산성 제고"). `[확인]`
- **1,000억원 GPU 클러스터**, 2026년부터 **연 약 300억원을 임직원 AI 툴 예산**으로 편성. `[확인]`
- 2026-02 CAIO 신설(이강욱), AX 총괄 VP(임경영) 별도. AI 연구 인력 약 150명(자체 주장). `[확인, 자체 주장]`
- **사내 시스템 3종** — `크래프톤 플레이그라운드`(공통 AI 파이프라인) · **`AX 포털`(임직원 제작 결과물을 앱스토어 형식으로 배포)** · **FDE(Forward Deployed Engineer, AI 엔지니어를 각 부서에 파견)**. `[확인]`
- **비용 거버넌스** — 토큰비·시트비·개인구독비 통합 **대시보드 전사 공개** + **모델별 가성비 비교표**. 조직별 차등(리터러시 낮은 조직=사용 권장 / 표준화 조직=효율 강조). `[확인]`
- **자인한 실패** — 엔터프라이즈급 대형 툴 조기 도입, 안 쓰이는 툴 다수 개발. `[확인]`
- 서베이 결과 임직원 **97.6% AI 도구 사용**. `[확인, 자기보고]`

### ② 넥슨 — **바텀업 + 커뮤니티**
- **AI본부**(본부장 강덕원) 중앙 + 하위 `AI HUB실`·`AX-Tech실`·`네비게이터실`·`콘텐츠생성AI팀`. 인텔리전스랩스는 약 800명 규모 데이터/AI 조직. `[확인]`
- **Claude·Gemini 등 18종+ AI 서비스**를 직무별 신청·지급. **슬랙 AI 커뮤니티 약 3,000명** + 중앙 모니터링의 이중 전략. `[확인]`
- **자인한 실패** — 로컬 머신 제어 도구(오픈클로) 전사 도입 검토 후 **중단**. 사유 = 빠른 업데이트 주기·보안 이슈·인프라 비용. 교훈 = *"기술적으로 가능한 것과 지속 가능한 것은 다르다"*. `[확인]` ← **우리 팀 의사결정에 그대로 쓸 문장**
- **모노레이크(Mono Lake)** — Snowflake 기반 단일 데이터 레이크. 1.0에서 **비용 25%↓·성능 17배↑**(보도 기준). 2.0은 AI Search(자연어→리포트)·온톨로지 팩토리. 쿼리 빌더로 비엔지니어 데이터 접근 민주화. `[확인, 자기보고 수치]`
- **NDC26 내러티브 세션(이지영)** — 세계관 초안 **179자 프롬프트 → 2분 만에 12,000자+, 70%+ 실사용**. 반면 캐릭터 대표 대사는 맥락 오해로 **실패**. 결론 *"AI는 실행 도구이지 의사결정자가 아니다"*. `[확인]`

### ③ 넷마블 — **1인 1에이전트 + 사내 지식 검색**
- **AI전략실**(2025-10 개명, 구 AI&Tech랩) 구성 = **플랫폼개발팀 / 에이전트개발팀 / 미디어개발팀** 3팀. `[확인]` ← 소규모 사내 AI 조직의 현실적 롤모델
- **Gemini 전 직원 기본 제공**, ChatGPT 신청제. **NDIS**(채팅으로 사내 지식 검색). 개발·QA·사업 멀티에이전트. `[확인]`
- ⚠️ AI센터 설립 연도를 2014년 / 2018년으로 매체가 다르게 적는다. **인용 시 주의.** `[확인된 불일치]`

### ④ 컴투스 — **AX HUB + 정량 공개**
- **AX HUB** 전담 조직, **FDE(현업 밀착형 AI 엔지니어) 배치 조직 신설 준비 중**. `[확인]`
- 국내에서 드물게 숫자를 공개 — AI ART Camp 교육 4개월 후 **수강자 82%가 작업시간 30%+ 단축**, 검수·수정 시간 **60%+ 감소**. 전사 1인 1 Agent를 **Claude Code + Codex**로 전개. 사내 세미나 세션의 **81%가 AI 주제**. `[확인, 자기보고]`

### 기타
- **NC AI**(2025 분사) — VARCO 제품군(3D/Sound/Voice/SyncFace/Translation/Safety). 리니지M 배경 원화 **2~3주 → 약 1주**, 아이온2 컷신 외주(3~4주)를 인게임 감정 파라미터로 대체. `[확인, 자기보고]`
- **카카오게임즈** — 전담 AI 조직명 **미확인**. 2026-01 Google Workspace 도입, 2026-04 임직원 AI 교육(바이브 코딩·워크플로 자동화·커스텀 웹앱, **사내 임직원이 강사**). `[확인]`
- **스마일게이트 AI센터**(2020-08 설립, "Human-like & Fun AI") — 게임 안의 AI 축. 사내 도구 배포 사례 **미확인**. `[확인]`

## 2. 해외 — 툴링 팀이 개발자에게 AI를 준 사례

- **Ubisoft `Ghostwriter`**(GDC 2023) — NPC bark 초안 대량 생성. **작가는 "생성"이 아니라 "선택·수정"**을 하고, 그 편집이 모델 개선으로 돌아오는 사내 RLHF 루프. `[확인]`
- **Ubisoft `Commit Assistant` / `Clever-Commit`** — 10년치 커밋 히스토리를 학습해 **커밋 시점에 버그 유발 가능성 경고**. La Forge(사내 R&D) → 프로덕션 이관 구조. `[확인, 보도·인터뷰]` ⚠️ 1차 공식 발표문 URL 미확인
- **EA SEED** — 연구조직이 실제 shipping까지 간 목록이 공개돼 있다. `Voice2Face`(음성→립싱크·표정 자동 생성, Battlefield 6·FC 25), `Swish`(ML 옷감), RL 골키퍼, 치팅 탐지. `[확인]` `[추정]` MMORPG 대사량을 감안하면 **음성→페이셜 자동화가 ROI가 가장 명확한 첫 타깃**.
- **Roblox** — `Cube 3D` 생성 모델을 **가중치까지 오픈소스** 공개(github.com/Roblox/cube). 더 중요한 건 `creator-docs`가 오픈소스라 **Studio Assistant / Code Assist / Texture Generator의 문서·권한·실패 UX 설계를 통째로 읽을 수 있다**는 점. `[확인]` ← 툴링 팀 최고 학습 교재
- **King** — Candy Crush 13,000+ 레벨을 **AI 봇이 먼저 플레이해 클리어율 예측**, 사람은 이상치만 검토. `[확인]` ⭐ MMORPG 콘텐츠 QA에 그대로 이식 가능. vault 기존 노트 [Improving Playtesting Coverage via Curiosity-Driven RL Agents — 자동 커버리지 탐색](automated-playtesting-shooterbot.md)의 상업 사례판.
- **Microsoft Muse(WHAM)** — Nature 논문. 게임플레이 영상+컨트롤러 입력 동시 생성으로 **디자이너 아이디에이션 도구**. `[확인]`
- **Riot** — 방향성만 공개(생성 모델로 3D·텍스처·애니 보조, "아티스트 대체 아님"). 구체 사내 툴명 **미확인**. `[확인]`
- **Blizzard/Activision** — 사내 이미지 생성 도구 사용 및 아티스트 반발이 **보도로만** 존재. 정식 명칭·1차 발표 **미확인**. 인용 시 "보도 기반" 명시.

## 3. ⚠️ 정치적 맥락 — 이걸 모르면 도구를 배포해도 안 쓴다

`[확인]` GDC 2026 State of the Game Industry(표본 2,300+):
- 젠AI 업무 사용 **36%**(스튜디오 개발직 30% / 퍼블리싱·마케팅 58%)
- 용도 — 리서치·브레인스토밍 81%, 일상업무 47%, **코드 어시스트 47%**, 프로토타이핑 35%
- **젠AI가 산업에 부정적이라 답한 비율 52%**(전년 30% → 2년 전 18%). **아티스트 64% · 디자이너 63% · 프로그래머 59%**

`[추정]` 툴링 팀의 실제 난이도는 기술이 아니라 **수용**이다. Ubisoft Ghostwriter(작가가 고른다)·Riot("대체 아닌 강화")·넥슨(바텀업 커뮤니티)이 공통적으로 **"대체"가 아니라 "지루한 반복 제거" 프레이밍**을 택한 이유. 사내 도구 런칭 문구를 쓸 때 이 숫자를 기억할 것.
