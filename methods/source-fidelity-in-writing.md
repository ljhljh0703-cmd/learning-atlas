# 사본은 합치지 말고 각각 보존한다 — 서술 층 출처 충실

*작가 직접 지시(2026-08-27, myth-forge 레인) → 주간 회고에서 횡단 정본으로 승격(2026-09-06). 출처 기반 수집·해체·서술 작업에 상시 적용.*

취득 층의 충실성은 [WebFetch 는 lossy 요약 — 충실 학습은 clone 통독](webfetch-is-lossy-clone-for-fidelity.md) 가, 검증자 주장의 충실성은 [검증자의 주장도 환각이다 — 강한 주장은 1차 출처로 재-Gate](verifier-claims-need-regate.md) 가 맡는다. **본 규율은 그 사이 — 원본을 이미 확보한 뒤 그것을 문장으로 옮기는 구간**이다. 헌법 §링크 규칙의 「충돌하는 출처는 덮어쓰지 말고 양쪽 보존」이 링크·주석 층 규칙이라면, 본 규율은 같은 원칙의 **산문 층** 확장이다.

---

## 철칙

**확인된 구체를 흐린 말로 바꾸지 않는다. 충돌하는 사본은 중립 문장 하나로 합치지 않는다.**

---

## 단계 (강제 순서 — 각 완료 판정 명시)

1. **보존 먼저** — 수집 단계에서 원전의 사건·대사·소품·반복·사본 차이를 *전부* 남긴다. 무엇을 덜지는 작가만 정한다.
   - 완료 판정 = 원전에 있는 항목 중 내 산출에서 빠진 것을 하나도 못 댐.
2. **사본 분리 제시** — 사본 A 와 B 가 서로 다른 이름·화자·행동을 제시하면, 사본별 화자·대상·대사를 *각각 완전하게* 쓴다.
   - 완료 판정 = 「다른 인물」·「다른 이」 같은 통합 표현 0건.
3. **대사 우선** — 대사가 남아 있으면 화자와 상대를 밝힌 직접 대사를 먼저 싣는다. 요약은 대사를 대체하지 않는다.
   - 완료 판정 = 원전에 대사가 있는 자리에서 내가 요약으로 갈음한 곳 0건.
4. **반복 구분** — 원전의 의도적 반복은 보존한다. 내가 같은 사실을 풀어 말한 중복은 지우고 다시 쓴다.
   - 완료 판정 = 남은 반복 각각에 대해 「원전 것인가 내 것인가」를 답할 수 있음.
5. **파손부 처리** — `손상됨`으로 끝내지 않는다. 다른 사본·후속 판독·평행 전승을 먼저 찾고 **확정 본문 / 사본별 보완 / 평행 전승**으로 갈라 적는다.
   - 완료 판정 = 파손 표기 옆에 세 갈래 중 어디에 해당하는지가 적혀 있음.
6. **층 분리** — 소비자 본문에 검수 보고문을 넣지 않는다. 판독 불확실성과 편집자 충돌은 각주·사본 카드·이본 항목에서 근거와 함께 보존한다.
   - 완료 판정 = 본문에 「확인 필요」·「검토 결과」류 문장 0건.
7. **보내기 전 3문 점검** — 각 문장에 대해 ① 누가 말하거나 행동하는가 ② 누구에게 무엇을 하는가 ③ 구체 명사를 흐린 표현으로 바꾸지 않았는가.
   - 완료 판정 = 세 답이 모두 분명함. 하나라도 흐리면 **작가에게 제시하지 않는다**.

## 금지 합리화 + 적신호

| 합리화 | 봉쇄 |
|---|---|
| 「사본이 갈리니 중립적으로 쓰는 게 안전하다」 | 중립 문장은 안전이 아니라 **은폐**다. 갈린 그대로 둘 다 쓴다 |
| 「독자가 헷갈릴 테니 하나로 정리하자」 | 정리는 작가 권한. 나는 재료를 온전히 올린다 |
| 「원전이 반복적이라 지루하다」 | 원전 반복은 자산이다. 지울 반복은 **내가 만든 것**뿐 |
| 「파손부라 더 쓸 게 없다」 | 다른 사본·평행 전승을 찾기 전엔 부재가 아니다(lessons 「없음은 주장이지 관측이 아니다」) |
| 「불확실성을 본문에 밝히는 게 정직하다」 | 정직은 각주에서. 본문에 검수문을 섞으면 읽히지 않는다 |

- 적신호: 「다른 인물」·「다른 이」·「누군가」·「무언가」·「해당」·「자리」·「차례」·「조건」이 확인된 고유명사 자리에 등장 · 같은 사실을 여러 문장으로 재설명 · 화자 없는 대사.
- *letter 위반 = spirit 위반.*

---

## 예외 + 탈출구

- **작가가 명시적으로 압축을 지시한 경우** — 덜어내기는 작가 권한이므로 지시대로 줄인다. 단 원본은 별도로 보존한다.
- **분량 상한이 계약으로 걸린 산출물**(대본·제안서) — 본문은 줄이되, 무엇을 뺐는지 목록을 같은 폴더에 남긴다. 조용히 빼지 않는다.
- 모호하면 **더 남기는 쪽**으로 간다. 빼는 결정은 되돌리기 어렵고, 남기는 결정은 쉽다.

## 권한 경계

본 규율은 **서술 규칙**이다. Vault 정본·스킬·공개 원고의 자동 수정 권한이나, 공개·판매 승인을 뜻하지 않는다.

## 왜 (근거)

- **원 사고(2026-08-27, myth-forge)** — 서로 다른 사본이 `누이`와 `인안나`를 각각 제시하는데도 「다른 인물」로 합쳐 불확실성을 감췄다. `자리`·`차례`·`조건` 같은 추상 명사로 화자·대상·행동을 지우고 같은 반년 교대를 여러 문장으로 재설명했다. 원문 = 2026-W35.
- **횡단 재발(2026-09-06 주간 회고 실측)** — 같은 형태가 다른 두 레인에서 나왔다. 교육영상 레인에서 **원자료에 없는 문장 2건**을 지어냈고(09-03 챕터 게이트가 적발), 문학 레인에서는 **없는 판정 기준 한 벌**을 만들어 재판정 패키지를 조립했다(09-03 rev2 전면 재작성). 세 레인 공통이므로 프로젝트 가드가 아니라 횡단 정본으로 둔다.
- 잡은 쪽은 대부분 내가 아니었다 — 그래서 본 규율의 실효는 **자기 점검이 아니라 7단계 완료 판정을 산출에 남기는 것**에 달려 있다(absorb-model-routing 절대룰 #7 초안≠판정 주체).
