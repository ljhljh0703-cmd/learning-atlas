# 에이전트형 참조 이미지→영상 하네스 (장소 홍보영상 해체)

> **한 줄**: «이름만 치면 광고 영상»의 실체는 한 줄 프롬프트가 아니라 **①실제 사진 조사 → ②컷 설계 규칙 → ③참조 이미지 생성 → ④컷표 문안으로 참조형 영상 생성 → ⑤음량 보정 납품**을 순서대로 강제하는 긴 «감독» 지시문과, 그걸 수행하는 여러 AI 작업자 팀이다.

## 2. 감독 지시문의 구조 (인수분해 — 원문 전재 없음, 전문은 위 링크)

| 칸 | 막는 실패 | 규칙의 요지 |
|---|---|---|
| 역할·규격 | 틀 재사용 | «너는 이 영상의 감독» · 16:9·1080p·20초 · 장소가 바뀌면 이야기부터 새로 |
| 주인공 | 빈 공간 또는 사람 광고 | 주인공 = 장소. 사람은 조연(사람 보이는 컷 > 절반, 사람 주대상 컷 ≤ ⅓) |
| 실제 자료 조사 | 모델이 공간을 발명 | 상징 목록 검색어 5종(상징·상징물·명소·포토스팟·랜드마크) → 핵심 상징 2~3개 · 사진마다 원본 주소 기록 |
| 로고·간판 | 글자·로고 뭉개짐 | 로고는 **실제로 걸린 자리**(정문·현판·간판)의 선명한 실사진 기반 · 화면 위 로고 카드 금지 · **영상 문안에 글자를 쓰지 말고 «이미지2 정문의 교명석»처럼 이미지 번호로 가리킨다**(모델이 문안의 글자를 새로 그리다 무너뜨림) · 로고 쪽으로 **다가가는 카메라 금지**(가까이 가면 글자를 새로 그림) |
| 컷 설계 | 볼거리 부족 | 20초 ≈ 10컷 안팎(1~3초 섞기) · 서로 다른 자리 5곳 이상 · 같은 사진 확대는 새 자리로 안 셈 · 같은 대상 재등장 금지 |
| 사람·몸 | 얼굴·손 붕괴 | 얼굴 크게 한 편에 1번 이하 · 손끝이 글자·화면에 닿는 동작 금지 · 입 움직이는 대화 금지 · 한 컷 한 행동 끝까지 |
| 카메라 | 가짜 움직임 | (현재 공개본) 모든 컷 이동, 5종 이상 섞기, 앞뒤 대상 크기가 달리 변하는 실제 공간 이동으로 깊이 · 화면 확대·잎 흔들림만으로 움직임 대신 금지 · 없는 바람·가구 움직임 금지 |
| 빛·재질 | 플라스틱 광택 | 실제 광원 방향과 그림자 일치 · «현실의 작은 불균일함» · 과한 HDR 금지 · 영상 전에 모든 이미지를 광고 사진처럼 보정 |
| 영상 문안 | 이미지–컷 불일치 | 형식 = 이야기 / 연출 / 참조 번호 / **컷표**(번호·초 · 참조 이미지 · 대상·동작 · 카메라 · 다음 장면으로 잇는 법) / 보존 / 소리 |
| 소리 | 컷마다 끊기는 음악 | 0~20초 한 곡, 전환에 멈추지 않음, 효과음은 동작 시점에 음악 아래, 사람 목소리 금지 |
| 비용 | 실패 만회 과금 누적 | 견적 → 승인 → 1회 생성, 막히면 원인 보고·임의 재생성 금지 |
| 납품 | 수정 불가 | 영상 + 사용 이미지 + 문안 전문 + 사진·로고 출처 · 소리만 −14 LUFS·최고 −1dB 사본 |

## 3. 게이트에서 확인한 한계 (그대로 믿지 말 것)

1. **판본이 다르다** — 영상 05:19 화면 판본은 «카메라를 고정해 지켜볼지 장면마다 판단… 기법 수를 억지로 채우지 마», «감정 순간은 얼굴을 가까이 잡아도 좋아». 현재 공개본은 «모든 컷 이동·5종 이상», «큰 얼굴 1번 이하». **같은 프롬프트로 같은 결과를 재현한다는 전제가 없다.**
2. **지시 ≠ 준수** — 주차(P) 표지를 이름 표시 자리로 쓰지 말라고 적었지만 박물관 결과 01:05 에 큰 P 표지가 남았다. 규칙을 적는 것으로 검수가 끝나지 않는다.
3. **국소 수정이 국소가 아니다** — 회전목마 봉만 고치라 했는데 07:54→08:32 사이 남자 옷(검정 코트→파란 셔츠)과 구도까지 바뀌었다.
4. **한 줄이 아니다** — 03:21 화면은 이름 붙은 여러 작업자(팀장·검수자)가 원본·보정본을 대조하는 팀 하네스다.
5. **제휴 편향** — 설명란에 Artlist 제휴 링크. 성공률·총비용·총시간은 공개되지 않았다(모집단 없음).
6. **권리** — 웹에서 찾은 사진을 참조로 쓰는 것과 광고에 쓸 권리는 별개(Artlist 라이선스: 입력 권리는 사용자 책임).

## 5. 기존 지식과의 차이 (delta)

- [Higgsfield 영상 프롬프트 공예 (AI Filmmaking as Directed Craft)](higgsfield-video-prompt-craft.md) 는 **에셋을 먼저 만들고 스타일 접두어로 고정**하는 방법. 이 노트는 그 에셋을 **웹에서 찾은 실제 사진으로부터 조사·생성**하는 앞단(①)과, **글자를 문안에 쓰지 않고 이미지 번호로 가리키는** 영상 모델 실패 회피 규칙, **견적 승인 1회 생성** 비용 규율이 새롭다.
- 작가 공정(SKILL)과 겹치는 원리: 참조 이미지 먼저(=블렌더 시안 6장 먼저) · 한 곡 음악을 영상과 분리 관리 · 음량 보정 사본. 새로 들일 것 = **컷표 형식**(참조 번호·카메라·다음 장면 잇는 법 한 줄)과 **생성 후 전 프레임 대조**(지시 ≠ 준수).
