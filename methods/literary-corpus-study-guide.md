# 문학 기법 학습 입구

**막힌 문제 하나를 고르고, 기존 자료에서 원리 하나를 꺼내, 내 소재에서도 쓰이는지 확인한다.** 카드를 외우거나 원작 문장을 닮게 쓰는 게 목표가 아니다.

## 여는 곳

| 순서 | 열 곳 | 무엇 |
|---|---|---|
| 1 | 학습 시작 안내 | 문제별 들어가는 곳 · 개념 6묶음 · 15분 연습 순서 · 대조 연습 · 빈 사용 기록 양식 |
| 2 | 현재 카드 목록 | **현재 카드를 읽는 기본 목록.** 막힌 증상 10묶음으로 찾는 덱 90행 + 승인 카드 48장. 2026-09-21 보정된 4카드 문구가 반영된 현행 덱(`cards-90.tsv`)과 대조했다. 덱 자체를 열려면 덱 색인 · 증상별 |
| (역사) | 옛 카드 목록(봉인 스냅샷) | **보정 전 문구를 담은 반영 전 기록이다. 최신 문구로 읽지 않는다.** 네 카드(`KOJ-2021-T2-TDC` · `MAE-2021-T2-TDC` · `MAE-2023-T1-CPR` · `SEG-2024-T1-TDC`)의 레버·중단 신호가 현행과 다르다. 봉인 파일이라 고치지 않는다 |
| 3 | 원본 | 카드 정본 literary-award-craft-cards-2020-2026 · 덱 `applications/_contest/deck/_data/cards-90.tsv` |

내용과 근거는 **봉인 패킷에 그대로 둔다.** 여기에 옮겨 적지 않는다 — 사본이 둘이면 한쪽이 낡는다.
시작 안내(1행)의 본문은 봉인 당시 그대로이며, 그 안의 카드 목록 링크는 옛 스냅샷을 가리킨다. **카드를 찾을 때는 위 2행 현재 목록으로 간다.**

## 실전 글쓰기 추가 읽기 (2026-09-21)

문체를 실제 글에 옮길 때 무엇을 고르고 어떻게 확인하는지에 관한 조사·시험 기록이다. 규칙이 아니라 참고다.

| 열 곳 | 무엇 | 한계 |
|---|---|---|
| 조사 노트 · `research/SOURCES.tsv` | 정보 공백·초점화·관찰 학습 원전 대조 | 아래 원전 상태 표 |
| 익명 비교 검토 · `eval/RESULTS.json` | 같은 합성 과제 2건을 기존안·보정안으로 쓰고 이름을 가린 채 비교 | **결과는 혼합이다.** 새로 쓰기에서는 기존안을 약간 선호, 고쳐 쓰기에서는 보정안 선호(기존안이 의도에 대한 불확실성을 부정으로 강화). 다듬기 1건은 지정 오탈자만 고침. 합성 과제이며 작가 원고·작가 반응·산문 전반의 우열이 아니다 |

**원전 상태 — 읽은 것과 못 읽은 것을 섞지 않는다.**

|---|---|---|

| 정현숙 (2012) 「신빙성 없는 서술과 내적 초점화」 | **본문 미확보** — 서지·초록만(유료 미구매) | 초록을 규칙으로 올리지 않는다 |
| Sternberg (2003) 「Universals of Narrative … (II)」 | 본문 확보 — 지정 구간(pp.518–524)만 | 1978 원서의 정의를 대신하지 않는다 |
| Braaksma 외 (2004) 관찰 학습 연구 | 본문 확보 — 지정 구간(pp.8–12, 27–30)만 | 학생 대상 쓰기 과정 실험이다. **성인 문학 창작·AI 글쓰기 효능 증거로 쓰지 않는다** |

## 문체·집필 연구 확장 (2026-09-22)

문체를 적용할 상황을 찾으려면 문제별 실전 찾기표에서 시작한다. 전체 자료·읽은 범위·보류 이유는 수집 묶음 안내에 있다. 작가 귀속 예문과 AI 초안, 외부 연구·작가 인터뷰를 구분했다. 외부 연구는 작가의 문체 기준이나 한국어 소설 효과를 대신하지 않는다. 실제 작가 원고 적용·작가 채택은 별도 확인한다.

## 쓰기 전에 알 것

- **카드 48장과 덱 90행은 겹친다.** 138개의 서로 다른 기법이 아니다. 두 집합의 상태를 서로 옮기지 않는다.
- **코퍼스 293편을 새로 해체한 결과가 아니다.** 705칸 원장의 반려와 세 축 등급 보류는 그대로다.
- **학습 전이 연구 4편**(인출·자기설명·사례 비교)은 회상·과학 이해·유추·협상에서 나온 결과다. 문학적 성과로 일반화하지 않는다. 15분 순서는 조사자가 짠 응용 설계다.
- **쓰임은 세 단계로 나뉜다** — 덱 계약(`applications/_contest/deck/technique-deck-v0.md`)을 그대로 따른다.
  - **읽기**: 작가가 학습을 부르면 이 입구·카드·덱을 읽는다.
  - **제안**: 실제 원고 작업 중 증상이 맞으면 카드를 먼저 제안할 수 있다(`proactive_suggestion: allowed_on_symptom_match`).
  - **원고 적용**: 작가가 수락한 뒤에만 넣는다(`application_gate: author_acceptance_required`). 수락 없이 원고에 넣지 않는다.

## 이 입구가 바꾼 기존 설명 2건

조사 중 기존 장부의 설명 2곳이 원전보다 넓게 적혀 있었다. 둘 다 원전을 직접 대조해 고쳤다.

- focalization-unreliability-ledger §1-1 — 「독자만 앎 = 파랄렙스」에 **그 글이 세운 정보 규범을 어겼을 때만**이라는 조건을 붙였다.
- poetics-recognition-ledger §1-3 — 「발견과 급전이 한 문장 안에 와야 하고 떨어지면 등급이 떨어진다」를 **고전 비극의 선호**로 되돌리고, 현대 단편 관측에는 등급으로 쓰지 않도록 고쳤다.
