# 결과물 위에서 판단하게 하는 제작 — BotW CEDEC 2017

> ⚠️ **provisional** — 출처가 **공식 슬라이드가 아니라 2차 요약**이다. 공식 세션 페이지·동시대 보도로 교차확인했으나 원 슬라이드 대조는 안 됐다. 인용 시 이 등급을 함께 적는다.

## 한 줄

**레벨 설계와 제작 관리를 분리하지 않았다.** 작업 맥락을 월드 좌표에 붙였다.

## 일곱 가지

1. **공간에 붙은 작업 맥락** — 월드 안 표식에서 담당 작업·사양·회의 정보를 바로 연다. 상위에서는 Field Task View 로 중복 작업을 막았다.
2. **삼각형 법칙** — 산과 언덕이 「넘어갈까 돌아갈까」 선택을 만들고, 가려진 목표를 점진적으로 드러낸다. 크기별로 랜드마크 / 분기·가림 / 미세 상호작용 역할을 나눴다.
3. **중력과 히트맵** — 중요도와 가시성이 다른 구조물을 배치하고 플레이 경로 분산을 히트맵으로 확인했다. **강제 waypoint 대신 연쇄적 호기심.**
4. **버그도 작업 단위** — `ZELDA_ERROR` 와 편집기 내 보고 경로. 버그를 막판에 몰아 처리하지 않았다.
5. **표현 감소 후 신호 보강** — UI 요소를 줄이되 애니메이션·순간 강조로 인지성을 회복. 정보량과 신호 강도는 직교한다.
6. **데이터 기반 저작 도구** — UI 디자이너 2명이 감당 못 할 2,344개 화면을 절차적으로 만들고, **비개발 직군이 게임 위에서 미리 보고 조정**하게 했다.
7. **환경음 우선순위** — 상시 반복 음악 대신 환경음·장소 음악·전투음을 우선순위와 공간 emitter 로 섞었다.

## 적용 (Absorb-to-Apply)

**삼각형 지형을 문자 그대로 가져오지 않는다.** 지형이 없는 게임에도 남는 두 가지만 옮긴다.

- **가시성 순서 테스트** — 화면 안에서 `현재 목표 → 옆의 유혹 → 다음 목표` 가 이 순서로 눈에 들어오는지 본다. 삼각형 법칙의 지형 없는 판.
- **좌표에 붙은 이슈** — 제작 이슈를 장면·레벨·오브젝트 좌표에 연결한다. 「어느 파일」이 아니라 「어느 자리」로 여는 것.

**파킹** — 4·6·7(버그 워크플로우 · 절차적 저작도구 · 오디오 우선순위)은 현재 프로젝트 규모에서 과잉이다. 트리거 = 화면 수가 두 자릿수를 넘거나 비개발 협업자가 생길 때.
