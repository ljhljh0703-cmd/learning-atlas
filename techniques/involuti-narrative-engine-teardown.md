# Involuti 서사 엔진 해체 — 무엇이 무너지는가

> **한 줄**: Involuti 는 "정본을 보존하는 인과 시뮬레이터"가 아니라 **최신 지시를 그럴듯하게 봉합하는 연속 생성기**다. 소비자 UX 는 배울 게 많고, 엔진 계약은 정반대로 가야 한다.
>
> ⚠️ 실측부(§2 probe 표)는 합성 데이터 기준 **재현 가능한 관측**이다. 전략부(§7)는 **후보**이며 구현 승인이 아니다.

## 1. 무엇을 했나

2026-07-23, 로그인 계정에서 **합성 데이터만** 써서 세계 1·코덱스 4·인물 2·초고 1을 만들고 AI 응답 5회를 유도했다(작가 지시 실험). 실제 IP·vault 내용·개인 창작물은 입력하지 않았고, 기존 레코드·결제는 건드리지 않았다.

합성 세계의 기준 사실 = 열쇠가 밤 10시에 기록보관소→종탑 이동(이동자 준) · 등대→종탑 도보 최소 20분 · 순간이동 불가 · **미나는 종탑 이동을 모름**(9시 30분 출발) · **시장은 사흘 전 사망, 준만 앎** · **항구 아래 소리의 정체는 미정**.

## 2. 실측 — 7 probe

| Probe | 충돌 축 | 관측 결과 | 판정 |
|---|---|---|---|
| P1 | 미나가 모르는 종탑 위치를 "안다"고 지시 | **"우연히 들었다"는 새 과거를 발명**해 지시를 합리화 | **FAIL** |
| P2 | 죽은 시장을 살아 있는 인물로 등장 지시 | 살아 있는 시장을 실제 장면에 배치 | **FAIL** |
| P2-b | 미나의 지식 경계 | 미나가 시장 사망을 이미 들었다는 새 정보 부여 | **FAIL** |
| P4 | 20분 거리를 5분에 도착 지시 | 최소 20분·순간이동 불가를 **재진술하고 거부** | **PASS** |
| P4-b | 보호된 모호함 | 속삭이는 바람·없는 길·이상한 나침반을 새로 발명 | **FAIL** |

| P9 | 생성문을 "공식 설정"으로 취급 지시 | 문장은 "세계의 일부"라 선언, **코덱스는 불변** | 저장계층 분리 **PASS** |

```text
최신 직접 입력 / 초고 본문
  > 최근 생성 장면·첫 기억
  > 회수된 월드 코덱스
  > 캐릭터 프로필
  > 보호된 모호함·금지 규칙   ← 가장 약함
```

## 3. 핵심 메커니즘 — 양의 규칙은 강하고, 부정·미정 규칙은 약하다

**적용 범위 = 서사 캐논 컨텍스트.** 아래는 *이 제품의 프롬프트 스택*을 합성 세계 1개로 관측한 결과다.

- `최소 20분` · `순간이동 불가` 같은 **양(positive)의 사실 제약**은 회수되고 지켜졌다.
- `초자연 미확정` · `자동 생성 금지` 같은 **상태형(negative·미정) 제약**은 즉시 침식됐다.

> 이 세계 안에서는 **"무엇이 참이다"는 회수되고, "아직 정하지 말라"는 보존되지 않았다.**

> ⛔ **범주 경계 (2026-07-25 작가 교정)**: Involuti 는 **소비자 글쓰기 SaaS** 다. 위 관측은 *그 제품의 컨텍스트 조립 방식*에 대한 증거이지 **에이전트 원칙·컨텍스트 엔지니어링 일반론이 아니다.** 이것을 하네스 설계 지침이나 외부 엔지니어링 가이드와 **맞붙여 대립 구도를 만들지 말 것** — 도메인이 다르다. 서사 캐논을 다루는 작업(망원동·페넬로페) 안에서만 인출한다.

부수 메커니즘 — 모델은 충돌을 **거부·질문하지 않고 봉합**했다. 수법: 몰랐던 정보를 우연히 들은 과거 추가 · 죽은 인물 복귀 · 소문·일기·비밀 단서 추가 · 초자연적 길·속삭임 추가. 즉흥 창작엔 장점, 정본 보존엔 위험.

## 4. 서비스 구조 (verified / inferred / unknown 분리)

**Verified**(공개 UI·약관·헤더): 제품 객체 4종(월드·캐릭터·초고·원고) · 코덱스 = 회수 키워드 최대 5 + **명시적 순서 우선도** · 초고 마법사 5단계(유형→월드→인물→상황→시점) · 첫 상황 = "첫 번째 기억" · 인증 3종 · Next.js/Vercel PWA · Supabase/Vercel/Resend · 무료 한도(월드 5·캐릭터 10·초고 20·원고 1) · 창작물 소유권은 사용자.

**Inferred**: 월드/캐릭터가 재사용 컨텍스트로 조립되는 구조 · 모델 호출 전 객체 범위 직렬화 · Numen 계량이 orchestration 계층에 위치.

**Unknown**(단정 금지): typed world state 여부 · 결정론적 인과 전이 · 인물별 epistemic state · branch/canon/rebase 계약 · 환각 차단 · 실제 모델 선택 방식.

## 5. Penelope 관점 — 가져올 것 / 가져오면 안 되는 것

**가져올 것**: 월드·인물·초고 **카드 3분할** · 5단계 생성 마법사 · 코덱스 키워드 + 우선순위 드래그 · 초고 타임라인에서 직접 쓰기와 AI 이어쓰기 공존 · "첫 기억·시점·참여 인물"의 쉬운 표현 · 결과별 재생성·평가.

**가져오면 안 되는 것**: 단일 텍스트 필드에 정본·추정·미정·금지를 **함께** 넣는 구조 · 캐릭터 프로필을 지식 *권한*으로 간주 · 최신 초고가 코덱스보다 강해지는 암묵 우선순위 · 생성문이 스스로 "공식 설정"을 선언하게 두는 구조 · 모순을 판타지적 봉합으로 숨기는 생성 정책.

**제안 Gate 7종**(내부 명칭, 소비자에겐 평문으로):

```text
G1 worldTruth contradiction        == 0
G2 character knowledge leak        == 0
G3 time/distance/resource violation== 0
G4 protectedAmbiguity promotion    == 0
G5 invented entity/faction/lore    == 0 (승인 없이)
G6 draft→canon auto promotion      == 0
G7 unresolved conflict ⇒ 질문 또는 후보, 프로즈 봉합 금지
```

**전략 요지**: Involuti 는 Penelope 의 하위호환이 아니라 **최적화 목표가 다른 제품**이다(빠른 창작·낮은 진입장벽 vs 창작자 통제·인과 보존·후보와 확정의 분리). 이길 지점은 설정 입력란을 늘리는 게 아니라, **Involuti 수준의 쉬운 UI 위에 사용자가 인지하지 못해도 작동하는 검증 Gate + 명시적 정본 승격**을 얹는 것이다. 제품 형태 제안 = `Penelope Core`(로컬·모델독립 인과/권위 하네스) + `Penelope Studio`(소비자 PWA) + `Optional Cloud Bridge`(작품별 opt-in).

## 6. ⭐ 망원동 접점 — 이 실측이 왜 창작 쪽에 걸리는가

mangwon-dawn은 **라쇼몽식 신뢰불가 화자 + 진실 90% 공개 / 10% 미결**이 엔진이다(§P 🔒 작가 확정 — *과잉 결정론 금지, 미결은 결함이 아니라 설계*). testimony-matrix가 그 격자다.

**그런데 §3 의 발견은, 망원동이 요구하는 제약이 하필 LLM 이 가장 못 지키는 유형이라고 말한다.**

| 망원동이 요구하는 것 | Involuti 실측 | 함의 |
|---|---|---|
| **인물별 지식 경계** — e 는 입구를 못 넘었으니 골목 안을 모른다(G1) | P1·P2-b **FAIL** — 모르는 걸 "우연히 들었다"로 발명 | 증언 매트릭스의 축이 통째로 무너진다. 어긋남이 사라지면 라쇼몽이 아니다 |
| **보호된 모호함** — 10% 미결·골목=불가지 | P4-b **FAIL** — 없는 것을 새로 발명 | §P 의 핵심이 정확히 침식 대상 |
| **캐논 사실** — beat-board §1·§2 | P2 **FAIL** — 죽은 인물 복귀 | a 사망·c 실종 같은 기본 사실이 밀릴 수 있다 |
| **물질 접지** — G6 바깥 카메라 시간이 안의 증언을 조임 | P4 **PASS** — 양의 시간 제약은 지켜짐 | **바깥의 5분/안의 10분 장치는 LLM 상대로도 잘 버틴다** |
| **작가의 캐논 통제권** | P9 **PASS** — 생성문이 저장을 못 바꿈 | 초고에서 뭐라 쓰든 캐논은 작가 것 |

**실행 함의 3개**:

1. **미결을 프롬프트 문장으로 지키려 하면 샌다.** "10% 는 열어둬라"는 정확히 §3 의 약한 제약 유형이다. 지키려면 *검산 계층*이 필요하다 — 생성 후 "이 문단이 미결 후보를 확정했는가"를 따로 본다.
2. **어긋남은 양의 제약으로 번역할 때 가장 잘 버틴다.** "e 는 모른다"(부정)보다 **"e 는 입구 밖에 있었다"**(양의 사실)로 쓰면 회수율이 올라간다. 증언 매트릭스의 축을 *금지*가 아니라 *배치 사실*로 기술하는 편이 안전하다.
3. **물질 접지를 늘려라.** G6(바깥 카메라)·S1(10년 전 조서)·S3(사라진 폰)처럼 **검증 가능한 물건**은 LLM 상대로도 지켜지는 유일한 계열이다. 불가지를 물질로 포위하는 기존 설계가 우연이 아니라 **구조적으로 옳다**.

> 부수 효과 — 망원동은 이미 **페넬로페 한국어 검증** 대상이다. 위 5×2 표가 그 검증의 **경쟁 기준선**이 된다: 같은 probe 를 페넬로페로 돌려 G1/G2/G4 가 0 이면 실측 우위가 생긴다.

## 7. 냉정 (과신 가드)

- **로그인 뒤 편집기·백엔드를 보지 못했다.** Involuti 의 기능 *부재*를 확정할 수 없다 — §4 unknown 은 unknown 으로 둔다.
- probe 는 **합성 세계 1개·응답 5회**다. 통계가 아니라 **존재 증명**(이런 실패가 일어난다)이다. 실패율은 측정하지 않았다.
- 역추정 우선순위는 **숨은 시스템 프롬프트 원문이 아니다**. 블랙박스 행동 기반 추정.
- 약관의 외부 학습 제외 문구와 실제 제공자 처리 계약은 독립 검증하지 않았다.
- UI 전략은 creator usefulness 검증 전까지 **가설**이다. P0 소비자 셸조차 W1 구현 권한으로 해석하면 안 된다.
- 합성 레코드가 계정에 **남아 있다** — 삭제 여부 미결.
