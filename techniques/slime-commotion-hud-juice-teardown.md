# 슬라임 대소동 — 모바일 호드 ARPG의 HUD·피드백 해체

> **정체**: `minimum_studio_game` 제작 **슬라임 대소동(Slime Commotion)** — 탑다운 액션RPG(슬라임 처치 + 용병·스킬 성장). **한국 App Store 유료 3위·액션 1위**(스타듀밸리 제침), Steam "대체로 긍정적". iOS+PC. 소스: 홍보 영상 포스터프레임 read-only 판독(2026-07-21). ⚠ **정지 1프레임(좌반부)만 관측** — 아래는 그 범위의 정직한 해체.

## 판독된 UI / 효과 (관측분)
- **뷰·아트**: 탑다운/약간 아이소, 밝은 **벡터 카툰**(픽셀 아님). 광택 슬라임 + 강한 실루엣 대비 = 호드에서도 개체 식별 쉬움.
- **적 색 위협즉독** ★: 초록 슬라임(잡몹) / 파랑 변종 / 검정(폭탄형) — **색만으로 위협 등급 즉독**. 텍스트 0.
- **개체별 플로팅 HP바**: 각 적 위 작은 **빨간 세그먼트 바** — 다수 적의 잔여 체력을 한눈에.
- **킬-쿼터 목표 HUD** ★: 하단좌 **"처치하세요 0/39"** — *지금 할 일*을 상시·명시. 목표 모호성 0, 루프 직진.
- **타이머 압박**: 상단 **⏱ 아이콘 + 세그먼트 바**(스테이지/웨이브 시간). 우상단 수치(웨이브/재화, 잘림).
- **스킬 발동 VFX**: 플레이어 옆 **보라 스타 버스트** = 능력 프로c 피드백(juice).
- **HUD 배치**: 코너 앵커·미니멀·고대비 = 모바일 세로 엄지영역 방해 최소.
- **AoE 텔레그래프**(Steam 보강): 큰 **흰 원**으로 스킬/공격 범위 예고 = 어디에 맞는지 즉독.
- **데미지 숫자 juice**(Steam 보강): 후반 전투에 88→176→352→405→810 데미지 숫자 폭발 = *인크리멘탈 파워판타지* 피드백.

## 성장·리텐션 루프 (Steam 페이지 보강, 2026-07-21)
> 캡션이 파는 "성장하는 재미"의 정체 — Steam 설명 + 전투 스크린샷 다수로 확인. (⚠ 순수 메뉴/스킬트리 UI 화면은 여전히 미관측 — 아래는 *설명 + 전투 내 발현* 근거.)
- **하이브리드 장르**(Steam 태그): 핵앤슬래시 · **인크리멘탈** · 로그라이트 · **아이들러** · 타워디펜스. → 호드 액션에 *방치형 성장 곡선*을 얹은 구조.
- **용병 파티**: 다수 용병 유닛이 함께 협전(모든 전투 샷 하단에 유닛 열). "차원을 넘어온 개성 넘치는 용병들과 힘을 합쳐".
- **메타 성장 축 4종**(설명): 방대한 **스킬 트리(빌드)** + **유물(relics)** + **특수 카드** 수집 + **무기 업그레이드**. = 로그라이트 빌드다양성 + 인크리멘탈 누적.
- **스케일링 킬쿼터 = 페이싱 장치**: "처치하세요" 목표가 39 → 65 → **1650**으로 폭증. 킬쿼터가 스테이지 난도·시간·성장 체감을 동시 조율(아이들러 곡선).
- **다중 바이옴**: 초록 협곡 / 사막 / 보라 야간 — 진행감·시각 신선도.

**설계 시사(재사용)**: *같은 킬쿼터 HUD 하나*가 초반 튜토(0/39)부터 후반 파워판타지(609/1650)까지 스케일을 표현 — **UI 재작성 없이 숫자만 키워** 성장 곡선을 태움. 인크리멘탈/방치형 페이싱의 저비용 레버.

## 왜 잘 통하나 (설계 레슨 — 재사용)
1. **"지금 뭘 하라"를 화면에 못박기** — 킬-쿼터(0/39)를 상시 표시. 호드 게임의 산만함을 단일 목표로 수렴. → 어느 액션 게임 HUD에도 이식 가능한 1급 규율.
2. **위협을 텍스트 아닌 색·실루엣으로** — 적 변종을 색으로 코딩([적 아키타입 디자인 패턴 — "스탯 묶음"이 아니라 "전술 질문"](enemy-archetype-design-patterns.md) 색 위협즉독의 실물). 읽는 부하 0, 반응속도 ↑.
3. **호드 가독성 = 개체 HP바 + 고대비 아트** — 수십 개체가 겹쳐도 잔여체력·종류가 구분됨.
4. **피드백(juice) 최소 1포인트** — 스킬 프로c에 명확 VFX. 입력→결과 체감(과함은 슬롭 경계, [HTML Sensory 품질 레버 (bespoke용)](../methods/html-sensory-quality-levers.md) Motion Gate 정합).
5. **모바일 우선 HUD** — 코너 앵커·고대비·요소 최소. #3 앱스토어의 실증적 배치.

## 냉정 한계 (반드시)
- **정지 프레임만 봄(모션 X)** — Threads 영상은 정지 1프레임, Steam은 스크린샷 다수. **영상 모션·전투 게임필·애니메이션·타격감은 여전히 미관측**. juice는 정지 VFX·데미지 숫자까지만 확인, 실제 game feel은 판정 불가.
- **순수 메뉴/스킬트리 UI 미관측** — Steam 스크린샷이 전부 *전투*라, 성장 축(스킬트리·용병관리·카드·유물)의 *실제 메뉴 화면·정보구조*는 못 봄. 성장 루프는 *설명 + 전투 내 발현*으로 재구성했을 뿐 — 메뉴 UI 해체는 여전히 **누락**(위 §성장 루프는 그 한계 안에서 읽은 것).
- **성공≠이 UI 덕** — 앱스토어 3위는 게임성·마케팅·가격·장르타이밍 종합 결과. UI는 일부. 과귀인 금지.

## delta / synergy (흡수 규율 ②③④)
- vault에 shipped 모바일 게임 HUD/juice teardown 없었음 = 깨끗한 delta. 인접: [적 아키타입 디자인 패턴 — "스탯 묶음"이 아니라 "전술 질문"](enemy-archetype-design-patterns.md)(색 위협즉독) · libgdx-rogue-os-art-guide · [픽셀아트 게임 에셋 제작 심화](pixel-art-game-assets.md) · [게임 재미 설계 OS (AI 위임용)](../methods/game-fun-delegation-os.md)(단 저긴 재미 지표, 여긴 HUD 표면).
- **반영처(Park)**: [학습→반영 루프 (Absorb-to-Apply)](../narrative/학습→반영 루프.md) ②Park — cookie-panic(하이퍼캐주얼, 모바일 HUD·킬쿼터·juice 직결) + hwiglija-tower-gdd(로그라이크 전투 HUD·적 색코딩) 착수/다듬을 때 §설계 레슨 인출. 현재 active 매핑은 candidate, 억지 반영 X.
- **선행 ④**: vault는 이미 [적 아키타입 디자인 패턴 — "스탯 묶음"이 아니라 "전술 질문"](enemy-archetype-design-patterns.md) 색 위협즉독·[HTML Sensory 품질 레버 (bespoke용)](../methods/html-sensory-quality-levers.md) 절제된 이펙트를 원리로 보유 — 이 게임은 그 원리를 *shipped 성공작으로* 실증. 개념 정합 확인.
- **북극성/취업**: 한국 인디 성공작 UI 패턴 = ai-game-roadmap(게임사 취업) 포폴 참고 자산.
