# 결정화(Determinization) 불완전정보 게임 AI — 고스톱 해체

> **경계·delta**: vault 게임 AI 코퍼스([적 의사결정 — Utility AI + GOAP 하이브리드 ("무엇을 하나")](enemy-decision-making.md) Utility/GOAP · [Dijkstra Maps — 격자 로그라이크 적 AI 의 공유 거리 필드](dijkstra-maps.md) · [DVM — 추론/결정/발화 분리형 소셜추론 NPC 결정 체인](dvm-decision-chain-npc.md) · [적 아키타입 디자인 패턴 — "스탯 묶음"이 아니라 "전술 질문"](enemy-archetype-design-patterns.md))는 전부 *완전정보·실시간 로그라이크* 적. **불완전정보(상대 손패·뒷패 안 보임) 턴제 게임 AI는 vault에 없다** — 본 페이지가 그 delta. 출처: `civilian7/gostop`(Delphi/FMX 고스톱) read-only 해체(2026-07-21). 스택은 니치(Pascal)지만 *알고리즘은 언어무관*이라 이식 가능. 문서 품질이 이례적으로 충실(자기 한계·미배선까지 정직 명시).

## 핵심 기법 1 — 결정화 + 그리디 롤아웃 (불완전정보 근사) ★
불완전정보(hidden state)를 다루는 표준 근사. **full MCTS(트리·UCB) 아님** — 의도적 단순화:
1. **결정화(Determinize)** — 실제 상태 복제 후, *안 보이는 카드만*(상대 손패 + 뒷패 더미)을 한 풀에 모아 **Fisher–Yates 셔플**로 재배치. 내 손패·바닥·먹은 패(공개정보)는 100% 그대로, 플레이어별 *장수*만 맞춰 되돌림 → 규칙상 항상 유효한 "그럴듯한 가상 세계 1개". 이제 그 세계는 *완전정보*가 됨.
2. **그리디 롤아웃(RunToTerminal)** — 그 세계에서 후보 수를 실행 후, 게임 끝까지 실수 없는 그리디(1-플라이 최댓값)로만 밀어붙임. 안전상한 4000턴.
3. **여러 세계 평균** — 다른 무작위 배치로 `SimCount`회(최대 12) 반복해 결과 평균 → "안 보이는 카드가 뭐였을지 몰라도 평균적으로 이 수가 얼마나 좋은가" 근사.
4. **TopK 가지치기** — 1-플라이 휴리스틱 상위 3개 후보만 몬테카를로 정밀평가(계산량 바운드).

## 핵심 기법 2 — 기대 *손익*을 목적함수로 (승률 아님) ★
롤아웃 종료 시 **실제 정산 로직(`TScorer.Settle`)을 그대로 재사용**해 순손익(Net)을 결과값으로 씀. 별도 "MC 전용 평가함수" 안 만듦. 효과:
- "이길 확률"이 아니라 **"평균적으로 얼마나 벌거나 잃는가"**를 직접 최적화 → 고박(독박 ×2) 위험이 크면 무리한 고를 자연히 회피(승률 최적화로는 안 나오는 판단).
- 게임 규칙이 바뀌면(고박 배수 조정 등) MC 판단도 자동으로 같이 바뀜 — **동기화 불필요**. 단일 진실 소스(규칙=정산 함수) 재사용의 모범.

## 핵심 기법 3 — 능력치 단일 노브 + 직교 성격축 ★ (난이도·캐릭터 설계)
**능력치(Skill 0~100) 값 *하나*가 4축을 동시 조절**: ①실수·무작위성 ②수읽기 깊이(0=1플라이 휴리스틱 / >0=MC) ③방어·견제 가중 ④고/스톱 판단 정밀도. `SimCount = round(Skill/100 × 12)`, `PickWithMistakes`로 최선수에서 확률적 이탈 → 고수↔하수 체감 격차.
- **성격은 능력치와 직교**: 배짱(GoBias)·욕심(Greed)은 캐릭터 고유값, 난이도와 무관. **"얼마나 잘 두나"=Skill / "어떤 성격으로 두나"=Bias·Greed** 분리. → AI 캐릭터에 실력과 개성을 독립 축으로 부여하는 깔끔한 설계.
- 재현성: 시드 LCG(좌석마다 다른 시드) → 디버깅·밸런스 튜닝 유리 + AI끼리 다른 패턴.

## 적용 트리거 + 체크리스트 (턴제·불완전정보 게임 AI)
**언제 인출** — 카드/보드/히든스테이트 턴제 게임에 AI 상대를 붙일 때, 또는 AI 난이도·성격을 설계할 때.
- [ ] **히든 정보가 있는가?** → 상대 모델링부터 하지 말고 *결정화*로 시작(안 보이는 것 무작위 재배치 → 완전정보화 → 롤아웃 평균). 싸고 규칙상 항상 유효.
- [ ] **평가 목적함수 = 실제 정산 재사용** → 승률 프록시 만들지 말고 게임의 진짜 점수/손익 함수를 롤아웃 종료값으로. 규칙 변경 자동 전파 + 리스크 인지 판단이 공짜로.
- [ ] **계산량 바운드** → TopK(휴리스틱 상위 N개만 MC) + SimCount 상한 + 롤아웃 턴 상한.
- [ ] **난이도 = 단일 노브** → 실수율·탐색깊이·방어가중·판단정밀도를 능력치 하나로 묶고, 최선수에 확률적 실수(PickWithMistakes)를 얹어 체감 격차.
- [ ] **성격은 별도 직교축** → 실력(skill)과 성향(공격성/욕심/배짱)을 독립 파라미터로. 같은 실력이라도 다른 캐릭터감.
- [ ] **재현성** → 시드 기반 PRNG(좌석/개체별 시드). 디버깅·밸런스 필수.

## 냉정 한계 (과대평가 가드)
- **상대 모델링 부재** — 결정화가 *완전 균등 무작위*라 카드 카운팅·상대 패 추정 없음. 롤아웃 속 상대도 전부 동일 그리디(각 캐릭터 성향 미반영). 즉 "지금 내 판단"에만 성격이 들어가고 *시뮬레이션 속 미래*엔 안 들어감 — 계산량 절감 근사(문서가 정직히 명시).
- **MCTS 아님** — 트리·UCB 탐색-활용 균형 없음. 그리디 롤아웃 1회/세계. 더 강한 AI 원하면 여기가 업그레이드 지점.
- **미배선 기능 정직 표기** — DerivedSkill(캐릭터 유도스킬)·Luck 스탯이 데이터엔 있으나 코드 미연결. *"문서가 엔진과 어긋나면 코드가 아니라 문서를 의심하라"* 명시 = SSOT 규율(아래 시너지).
- 스택 니치(Delphi/FMX) — 코드 직접 이식 X, *패턴만*.

## 시너지 · 관계 (작가 시스템)
- **문서=코드 파생 규율**: "엔진과 어긋나면 문서를 의심하라"는 code-as-SSOT 원칙 → vault [파생 원장 규율 (Derived Ledger Discipline)](../methods/derived-ledger-discipline.md)·SSOT 철학과 동형. 코드가 권위, 문서는 파생. 작가 vault가 이미 앞선 원리를 게임 프로젝트 문서화에 적용한 사례.
- **게임 AI 코퍼스 확장**: [적 의사결정 — Utility AI + GOAP 하이브리드 ("무엇을 하나")](enemy-decision-making.md)·[DVM — 추론/결정/발화 분리형 소셜추론 NPC 결정 체인](dvm-decision-chain-npc.md)(완전정보·실시간) 옆에 *불완전정보·턴제* 축을 추가. [WoC 역기획 — AI 게임 생산 방법론 (10종 해체 종합)](woc-ai-gamedev-teardown.md)(AI 게임생산)과 인접.
- **AI 캐릭터 성격 설계**: 실력↔성격 직교 분리는 [AI NPC 기억·신념 아키텍처 (Memory + Belief)](ai-npc-memory-belief-architecture.md)·페르소나 설계와 연결(단 저긴 대화 NPC, 여긴 대전 AI).
- **순수 참조(흡수 X, provenance-only)**: `docs/external-ai-guide.md`(구 Gemini/OpenAI/Ollama REST 호출 패턴)는 vault엔 저가치 — Gemini RETIRED·작가는 Codex 체제라 stale, 일반 REST 패턴은 기지식. 학습 트레드밀 회피(억지 흡수 X).
- **반영처(참조 후보 — 비권위, 2026-07-21 정정)**: 핵심(결정화·불완전정보)의 가장 깨끗한 후보 = **ai-npc-engine Werewolf**(숨은 역할 추정) — 단 LLM 인지가 주축이라 *보완층*으로만, 맹신 X. 곁가지(skill⊥성격 페르소나)만 combat-sim-harness-spec에 참조로 걸림(시뮬 골격만 닮음, 연결 약함 — 완전정보 전투엔 결정화 무관). *정정 이력*: 최초 combat-sim을 최강 후보로 과대평가 → 작가 지적으로 하향(combat-sim은 대개 완전정보라 결정화 미적용). **어느 쪽도 채택 확정 아님 — 판단은 작가.**
